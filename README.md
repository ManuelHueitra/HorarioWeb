# HorarioWeb

Aplicación web moderna para la creación, gestión y organización visual de horarios universitarios. Diseñada para reemplazar planillas manuales de Excel y facilitar la planificación académica.

## Tecnológico

- **Framework:** React + TypeScript
- **Tooling:** Vite
- **Estilos:** Tailwind CSS v4
- **Gestor de Paquetes:** pnpm
